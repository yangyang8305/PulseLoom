# Pulse Loom 主图方案：设计简报（给每位设计 agent）

## 产品与场景
Pulse Loom 是一款 iPhone 触觉（震动）App：首页上半部有一块约 400×440pt 的主图区域，下面是曲名、
一排节奏芯片、强度滑块和开始/停止按钮。主图在三种状态下显示：静止、震动播放中（有强度和节拍）、
跟随音乐（能量曲线 + 重拍）。App 整体审美：克制、优雅、有印度窗棂/曼陀罗式的极淡暗纹背景，
衬线斜体标题，粉灰（blush）主题，浅色和深色两套。

## 老板（产品主人）的原话，必须遵守
- "关键不是堆叠特效，而是细节的精致和布局的简洁，才有高级感。"
- 上一轮六个方案被否：太简单、几何基本形、像占位图。
- 上上轮的"花"被否：花瓣层叠太多、带描边，看着诡异。
- 老板肯定了两个创意方向但嫌做得糙：光球 → 应该做成带完整环系的土星；涟漪 → 应该是真正的水面，而不是一个圆。

## 你的任务
用 Canvas 2D 实现**一个**主图方案（方向已在任务提示里指定），输出到指定的 options/<id>.js 文件，
然后用 render.sh 渲染四帧，自己用 Read 工具看图，像一个挑剔的艺术总监那样审视，至少迭代两轮，
直到你自己认为它"精致、简洁、高级"，再返回。

### 文件契约
```js
window.OPTION = {
  name: '两到四字中文名', english: 'English name', note: '一句话（中文）说明静止/震动/音乐三态下它怎么动',
  tick(p) { /* 可选：每帧状态推进，p = { dt(秒), now(毫秒), env, state } */ },
  draw(p) { /* 必需：画一帧 */ },
};
```
`draw(p)` 的 p 字段：
- `ctx` CanvasRenderingContext2D（已 setTransform 处理 dpr，直接用 CSS 像素坐标）
- `w, h` 画布尺寸（440×470），`cx, cy` 建议中心（cy = h*0.46），`R` 建议半径（= min(w,h)*0.4 = 176）
- `now` 毫秒，`dt` 秒
- `env` 0..1 强度包络（快起慢落），`spring` 起音触发的弹簧量（-0.3..0.5 左右，正为向外），
  `hits` 最近 1.6 秒内的起音数组 `[{age(秒), gain(0..1)}]`，`rot` 累计慢旋转弧度（静止约 0.08 rad/s，随 env 加快），
  `breath` 0..1 的 10 秒呼吸
- `palette` `{bg, surface, ink, muted, line, accent, hero1, hero2, hero3}` 十六进制字符串；`dark` 布尔；
  `rgba(hex, alpha)` 工具函数；`reduce` 减少动态；`playing` 布尔；`state` 可持久的对象（放粒子等）
- 画布已被 `palette.surface` 填底。不要画边框。不要画文字。

### 硬性要求
- 只用 Canvas 2D，纯函数式绘制，不依赖外部库、不用图片、不用 `Date.now()`/`performance.now()`（用 `now`）。
  `Math.random()` 只能在初始化 `state` 时用一次（用 `state.seed` 或固定种子的简单 LCG 更好，便于复现）。
- 浅色和深色都必须好看：颜色只从 `palette` 取，用 `rgba()` 控制透明度；深色下不要出现发灰的脏块。
- 单帧绘制在 440×470 上应该 < 8 ms（粒子不超过几百个，不要每帧 createRadialGradient 几百次）。
- 布局简洁：一个主体，居中，周围留白；不要把画面填满，不要堆特效。
- 细节精致：细线（0.5–1 px）、多层次的透明度、有光影方向（光源左上）、边缘柔和、颜色相近而不是对比强烈。
- 动效优雅：静止时有极慢的动（旋转/漂移/呼吸），但 5 秒内看不出"在动画"；震动时随 `env` 有明确但不夸张的变化；
  每次起音（`hits`）有一个从主体出发、快起慢落的响应；音乐时上述叠加。减少动态（`reduce`）时只保留明暗变化。
- 代码 ≤ 300 行，结构清晰，有简短注释。

### 工作流程
1. 读 `engine.js`（信号模型）和 `options/sample.js`（契约示例）。
2. 写 `options/<id>.js`。
3. 运行 `./render.sh options/<id>.js`（在 art 目录下，约 25 秒），得到 `frames/<id>-{idle-light,heart-light,music-light,heart-dark}.png`。
4. 用 Read 看四张图。问自己：像不像一张值得挂在 App 首页的插画？细节是否经得起放大？浅深两色是否都成立？
   起音帧（heart-light，起音后 40 ms）与静止帧是否有可感知但不突兀的差别？
5. 修改，重渲染，至少两轮。最后再确认一次 JS 没有报错（渲染出来是空白或只有底色就是报错了）。
6. 返回结构化结果：文件路径、名称、一句话说明、你最得意的三个细节、你仍然不满意的一点。

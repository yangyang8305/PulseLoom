# 首次触感体验与中文错误整改（2026-10-15）

## 产品行为

- 开屏主操作为“找到适合我的触感”，进入设备确认、短体验和感受确认。仍可明确选择“暂时跳过，进入首页”。开屏与体验页可滚动，适应内容增大。
- 新体验从不高于 25% 的相对强度开始，两段触感合计 0.76 秒。每次均需手动开始，无自动升级或自动重播。
- 输出完成后才询问“合适／没感觉／太强”。没感觉提高一档、太强降低一档，档位范围 10%–100%。边界档位提供建议，不声称用户已获得满意感受。
- 停止按钮固定在体验页底部，不随长说明滚走；用户主动停止会停止当前输出，自动离页清理则只处理该体验拥有的输出。
- 无可用设备、启动失败、主动停止、后台中断或被其他播放替换时，不能保存为已确认的体验。停止、关闭只释放该体验拥有的输出，不误停后续其他会话。
- “合适”后事务保存常用 gain、可选 firstTouchGain 及 onboarded。新用户进入首页；已有用户重测可查看保存确认。音乐配置的强度保持独立。
- 新库默认 gain 从 0.8 改为 0.35；已保存的旧 gain 不重置。新增 firstTouchGain 是可选字段，旧库缺少该字段仍可读取；异常数值被作品库校验拒绝。
- 首页“调整触感→测试强度”、设置中的“第一次触感体验”均可重新进入；设备不可用时提供直接检查／更换输出设备和故障排查入口。

## 错误呈现

UserFacingError 负责把错误转换为当前 App 语言，统一覆盖 App 操作、音乐、编辑、作品库、购买、同步、远控、Watch 连接及触觉中断等显示边界。内部错误类型、交易校验、停机和数据保护逻辑保持各自原有职责。

已知错误保留具体原因和下一步；系统网络、文件、空间不足和未知错误使用对应的用户文案。已经本地化的 Localizable / Recovery 消息按资源键识别，避免把英文 SDK 描述直接显示给中文用户。未知 SDK 信息不直接进入提示。

音乐输出失败显示中文说明，并提供“检查或更换输出设备”按钮。商店与远控不可用提示不再要求普通用户核对商品配置或部署中继；去掉相同商店错误的重复展示。三种语言资源仍由 localizations.tsv 确定性生成。

## 实测边界

本轮系统与验收 UI 测试只使用现有 iPhone 17 / iOS 26.5 模拟器，没有切换或启动小屏模拟器；因此小屏布局尚未完成专项验证。模拟器只检查软件流程和可达性，不能证明实际马达强弱或身体舒适度，也没有注入 UI 硬件成功状态。实体设备上的触感强弱和舒适度仍需用户实测。本轮没有重新安装手机 App、购买或部署远控服务。

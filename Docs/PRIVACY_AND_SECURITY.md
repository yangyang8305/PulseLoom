# 隐私与安全：当前交接边界

本说明按 `088387a` 实际源码核对；完整逐路径、TTL、失败残留和固定代码引用见 [DATA_FLOW.md](DATA_FLOW.md)。源码审核及模拟器测试不代表生产部署或隐私合规认证。

## 用户数据去向

作品、草稿、偏好、可选历史及反馈主要在iPhone沙箱。私有CloudKit同步由用户开启并显式执行，只发送规定的作品/收藏/组合/墓碑和主题；不发送音乐文件、历史、草稿、反馈或交易状态。中继只处理内存房间和加密帧，但仍看到IP、鉴权token、房间/时间/长度等元数据。StoreKit/MusicKit使用Apple服务，没有自建用户交易数据库。

**不能用“100条/30日”和“500条/7日”承诺严格到期擦除。**历史只在加载/记录时筛选，磁盘旧副本可保留更久；诊断数组只在内存按记录时裁剪，OSLog由系统管理。音频正常替换会清理副本，但初始化失败或中止可能遗留临时文件。Exports/CloudStaging没有后台TTL清扫。中继IP表存在AUD-21，不能承诺IP仅保留60秒。

全量本机清除使用持久化意图和恢复机制，处理受管文件及previous；不会删除原音频、系统备份、外部分享、服务器已接收写入或远端房间。远控断开仍在进程内保留邀请供重连。云关闭不删云，云删除需已启用数据库且请求成功。不存在物理闪存安全擦除保证。

## 当前访问与内容规则

远控start/gain每次核对即时Pro、当前许可及输出ID。本机新会话接管后旧远控不能改动它。普通stop保权，emergencyStop撤权；安全停止不因Pro丢失被屏蔽。传输使用HTTPS/WSS、AES-GCM和room AAD；分享邀请携带密钥与capability，用户选定的分享渠道能看到它，不能公开发布。

禁止对外导出/分享付费预设及派生文件；原创作品仍能导出。整库含受限/来源未验证作品或引用时整体阻止，不能静默过滤。外部JSON不能认证原创；同账号CloudKit同步独立处理并保留来源。用户可见影响见 [ACCESS_POLICY_REVIEW.md](ACCESS_POLICY_REVIEW.md)。

没有广告SDK/ATT跟踪、HealthKit、位置、麦克风、摄像头或通讯录请求；敲击录制是触摸。模拟器包不注入假Pro、真实服务地址或账号，也不自动上传Appetize。用户手动上传后，第三方包和会话的保留规则独立于App本地清除。

## 正式发布前仍需完成

Privacy Manifest是声明起点；最终归档须对照Required Reason API、数据类型、关联性、用途、Tracking和App Store标签。当前OtherUserContent/OtherDataTypes的Linked=false不能仅靠无账号推定正确，必须结合私有CloudKit、IP及支持渠道复核。出口加密声明也需发行方核实，不作法律保证。

明确运营主体、区域、跨境及处理商、支持/隐私URL、日志轮转/保留、邀请忘记和用户删数流程。处理AUD-21及暂存清理风险后再单独授权部署。生产配置、私钥、证书、.env和令牌不得入Git。真实购买、CloudKit多设备、公网WSS、渗透测试、依赖扫描和真机验收均未完成。

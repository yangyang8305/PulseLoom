# PulseLoom 女性新手用户体验评估

日期：2026-10-14（日本时间）。评估版本：Git main `3be365a53c96a64b8c893ba3f120333b323455f7` 对应产品代码；使用上轮构建的相同产品源码模拟器包。

## 方法与边界

角色设定：一位不熟悉触觉技术、重视私密、舒适、自主控制，想快速体验节奏的女性新用户。这个设定不代表所有女性，也不假设女性都喜欢粉色、柔弱触感或同一种使用目的。

本次是角色化专家走查，不是真实女性受访者研究，亦不声称拥有女性身体感受。使用专用 iPhone 17 Pro / iOS 26.5 模拟器，通过真实界面操作欢迎页、两页引导、首页、触感调整、内置音乐加载及失败提示、录制两次触碰、命名保存、编排、我的、手动触感、设置、输出设备、隐私说明、远控入口和 Pro 页。存储采用新的 DEBUG UUID 隔离目录，没有动用户真实作品，未购买、未授权账号、未建立远控连接。锁屏行为另以当前源码核对。

实际马达感觉、噪声、温度、长时间使用、iPhone 15 单手操作、小屏/最大字体、实体 Watch、实体手柄和正式商店交易没有本轮体验证据。不能因为模拟器不能震动就认定实体设备失效。

## 主观总体评价

整体约 5/10：愿意试用，尚不足以让我放心付费并形成长期使用习惯。评分是本次专家判断，不是统计调查。

有统一的温柔视觉，也有基本的隐私与停止机制；但新用户需要自己研究预设、相对强度、设备限制、深层入口和技术错误。当前产品还没有把第一次成功体验组织好。

## 实际观察、用户影响与建议

| 范围 | 实际观察 | 用户影响 | 建议 |
|---|---|---|---|
| 产品用途 | 欢迎页为“个人震动，触感由你”，引导主要解释四页功能 | 知道能做什么，却不清楚适合何时使用、第一次怎么选 | 明确首要用途；提供一条短体验路径和可跳过的情境入口，不作效果保证 |
| 首次体验 | 可以跳过引导；设备测试是第二页的可选按钮；全新隔离库首页默认 80% | 用户还未建立个人感知基准，就面对较高的相对百分比 | 用渐进短测试询问“没感觉／合适／太强”，保存用户认可的默认档；不要规定全体女性应使用同一强度 |
| 首页效率 | 大幅装饰图占据主要空间，节奏、强度、开始停止集中在下部 | 氛围好，但核心任务的信息密度和可发现性不足 | 缩小闲置装饰；展示当前输出设备、短试听、手动入口、最近使用和收藏 |
| 预设选择 | 名称有“柔绽、缓浪、晨雾”等；当前选择有短描述；首页长横向列表 | 气氛名称不能帮助用户比较触感；列表后部难发现 | 每个选项配“短促／持续、疏／密、循环／单次”的简明标签和缩略节奏图；允许短试听再选择 |
| 控制语义 | 强度、速度、质感都能调，且有相对值说明；调整弹窗的自动锁定选择在截图中只明显显示“关” | 新手不清楚百分比与实际感觉的关系，也不易理解“关”属于哪个功能 | 以感知词辅助参数；显示明确字段名；区分节奏速度与其他质感调整 |
| 音乐 | 点内置曲目即可加载“慢步”，显示 01:24；有柔和／均衡／鲜明三档 | 内置样例让入门更容易，这一点应保留 | 首次优先推荐可用曲目，解释三档差异；本地文件与 Apple Music 条件分别说明 |
| 音乐失败 | 点击开始后显示英文“No haptic output is available.”，进度曾到 00:01，再回到可开始状态 | 中文用户不知道是设备、连接还是操作问题，缺少下一步 | 开始前检测可用输出；中文说明原因，提供“检查输出设备／测试触感”，不要只“收起提示” |
| 创作 | 能录制两次触碰并命名保存；按钮变为“已保存 · 更新保存” | 保存反馈清晰，真实流程可完成 | 保留该确认，同时提供“去播放／查看作品”快捷行动 |
| 录制反馈 | 结束后计数仍为 2，但面板恢复“开始录制后，在这里轻触”；内容需切换编排才看见两段 | 容易怀疑内容没有留下，不知道下一次录制是替换还是追加 | 在同一页显示已录时间线、触碰分布，明确“重新录制／继续添加”，提供预览和局部撤销 |
| 高级创作 | 编排页同时出现强度、质感、持续/短促、156 毫秒与138毫秒间隔等 | 对想保存喜欢节奏的人，学习成本过高 | 先提供模板和直观拖动，技术参数放进高级编辑；不要牺牲高级用户的精度 |
| 我的与手动 | 手动触感在“我的→更多体验”；主图、主题、Pro 占更靠前的位置 | 核心使用方式像附属功能；新手可能完全不知道它存在 | 首页放“按住体验／手动控制”；我的聚焦作品、收藏、隐私、设备和设置 |
| 手动操作 | 说明“按住感受，松手停止”，有独立停止；辅助功能树却将面板称为“节奏录制触控区域” | 按住/松手容易理解，但读屏语义与任务不符 | 保留直接控制；改为准确的手动控制标签，验证读屏和替代输入 |
| 输出设备 | 在“我的→设置→触觉输出设备”；显示连接设备与触觉能力，说明识别不等于可震动 | 状态诚实，但排查入口太深；新手未必想到手柄支持在这里 | 首页直接显示当前设备和连接/能力状态；无法输出时就近进入测试，不以诊断数值充当实际感觉 |
| 隐私 | 使用历史、诊断默认关闭；后台遮盖默认开启；音频本机处理有说明 | 默认有利于建立信任，是产品优势 | 首次用短摘要告知这些选择；保留详细说明，但避免要求用户读完整段协议式文字才理解 |
| 备份 | 页面提示付费、派生、未验证内容或相关引用可阻止整份库备份 | 自己的作品可能因混入其他内容而无法正常备份，容易失去信任 | 私人备份与对外分享分别设计；对受限项保存引用或提示重取，保障原创内容可恢复，不静默遗漏 |
| 远控 | 本包显示中继未配置，同时仍展示“创建邀请”；说明接收者主动许可、前台撤权 | 同意机制方向好，未配置服务却让用户面对开发问题 | 生产环境先保证服务可用；未就绪明确状态并停用无效主操作；始终明确接收者有最终控制权 |
| Pro | 当前包无法取得商品；提示重复两次，要求核对“商品配置”；无可评价格 | 用户会认为自己要解决开发者的问题，难以判断付费价值 | 将商店失败与开发配置分开；去除重复错误；明确免费/付费差异、一次性价格、设备条件、Pro 不增加马达功率 |
| 视觉与阅读 | 色彩、圆角、画面一致；浅色纹样、次级文字较淡，装饰在多页反复占用空间 | 有氛围但可能增加阅读和扫视负担 | 让视觉表现服务当前状态；提高关键说明可读性，提供简洁外观与减少动态选择；按大字体和小屏另做真人检查 |

## 女性角色下最重要的产品意见

1. 自己的舒适反馈应优先于工程百分比。不要替用户决定“女性应该偏柔和”，也不要让用户通过购买误以为能突破硬件强度。
2. 自主权应在画面上可见：谁能控制、当前上限、是否已停止、如何撤回，都应一眼理解。远控接收者不能靠读说明才发现撤回入口。
3. 若产品定位包含私密或亲密体验，文案需要明确边界而尊重使用者，不羞辱、不猎奇、不要求交出多余身份信息。该定位应先由产品明确，不能单靠粉色推断。
4. 不只评估静坐双手点屏幕。应测试单手、低光、低注意力和想立刻停止的情境；手小与审美均有个体差异。
5. 正式系统锁屏、App 内防误触、隐私遮盖是三个不同概念。当前源码中防误触会全黑并以三击解锁，期间输出继续；用户可能误以为系统锁屏或已停止。建议名称明确，并提供易记、可达的紧急停止方式。

## 建议的整改顺序与验收条件

| 优先级 | 改动 | 可观察的验收条件 |
|---|---|---|
| P0 | 首次设备检测与个人触感基准 | 新用户无帮助完成短测试；能回答当前设备、是否有感觉、怎么停止；没有感觉时有明确下一步 |
| P0 | 全场景停止、锁定与远控撤回 | 在普通、音乐、手动、防误触、远控接收场景实际测试；用户能迅速停止，界面状态与真实输出一致 |
| P1 | 首页重排与手动/设备入口 | 用户从首页能直接找到短试听、手动控制、当前设备和喜欢的节奏；装饰不挤掉核心操作 |
| P1 | 统一中文错误与能力说明 | 输出、商店、服务不可用时均说明原因和可执行下一步；生产界面不要求用户配置中继或商品 |
| P1 | 录制后反馈和预设可比较性 | 新手无需切工具即可看见刚录内容；能说明重新录制会发生什么；能区别循环和单次预设 |
| P1 | 备份、付费权益与可用状态 | 自己的原创作品可备份和恢复；权益、价格、依赖条件一致；未配置服务不作为可用付费能力承诺 |
| P2 | 小屏、大字体、真实 Watch 和单手优化 | 在目标设备实测并保留任务结果；布局通过不能替代可用性与真实触感检查 |
| P2 | 视觉主题、扩展内容与长期使用 | 核心体验完成后再优化动画、主题和扩展数量；通过回访确认是否值得再用 |

## 下一轮真实用户研究

建议先邀请 6–8 位背景不同的女性参与形成性测试，覆盖初次与熟悉节奏工具的人、不同手部操作习惯、不同审美与隐私要求。这个小样本用于发现问题，不用于宣称代表女性总体。

不要先教学，依次给任务：完成首次触感测试；挑一个节奏并调整到合适；判断当前输出设备；立即停止；加载音乐；录制保存并找回；理解远控撤回；判断 Pro 是否值得购买。记录完成情况、用时、误触、求助、困惑语句和再次使用意愿。在用户同意的范围收集必要反馈，避免不必要的私密身体描述。

本轮没有修改产品代码，没有推送新的评价文件。测试通过意味着既定断言通过，不能证明产品已经让普通用户感到好用。

# Pulse Loom v0.6 — 四页结构与简明交互

本版本为可运行的单文件 HTML 交互模型，不是原生 iOS App。

## 打开

用支持 JavaScript 的浏览器打开 `index.html`。CSS、图标、插画与脚本均已内嵌，不需要安装前端依赖或启动服务器。部分聊天附件预览器、iPhone 文件预览器不执行 JavaScript，不能用这类预览代替浏览器运行。当前没有完成实体 iPhone/Safari 验证。

## 四个主页面

- 首页：普通震动；6 个常用预设直接可选，“全部预设”打开完整 16 项；开始、暂停、停止、强度与定时。
- 音乐：独立底部入口；直接选音频文件或示例，自动解码分析，就绪后点击“开始跟随”。默认设置即可使用。
- 创作：独立底部入口；敲击创作、绘制变化、逐段编排、手势调节都保留。高级数值放在可展开区域。
- 我的：作品、收藏、主题、记录、权益、设置；组合、呼吸、手动、远控、Watch、组件及同步由“组合与更多体验”进入。

默认全功能演示，不会发生扣费。需检查免费边界时，从“我的 → Pro → 审查购买结果”切换模拟权益。

## 行为边界

真实执行：页面交互、编辑、预览动画、作品保存、JSON 导入导出、音频选择/解码/分析/播放、合成示例与声景。

仅模拟：手机马达、Core Haptics、Apple 支付、系统音乐授权、iCloud、远程连接、Watch 和主屏组件。本模型不读取其他 App 的音频，不绕过 DRM。音乐为原型级能量/瞬态分析，不能作为专业节拍识别或真机触感效果的证据。

音乐/声景在明确点击开始后会真实发声。切换到浏览器后台时暂停；回来不会自动恢复。

## 数据

v0.6 使用独立存储键 `pulse_loom_full_v06`。在同一可访问浏览器存储域内，会尝试读取 v0.5/v0.4 数据并复制至新键，旧键不删除。不同文件路径、浏览器或存储策略可能阻止这项读取。音乐仅保留在本次内存中，刷新后需重新选择；重要作品从“我的作品 → 导入与导出”备份。

当前模型没有网络上传、账号登录、广告 SDK 或第三方字体请求。存储受限或写入失败时有提示，不把失败当成保存成功。

## 文件

- `index.html`：可交互单文件。
- `source/`：模型源文件与构建脚本。
- `docs/UX_DECISIONS.md`：四页架构、操作路径、取舍与 Apple 参考依据。
- `docs/QA_REPORT.md`：本轮检查结果及未测范围。
- `tests/ux_regression.py` / `ux-results.json`：可复核测试脚本和实际结果。
- `previews/`：由本版运行界面截取的预览。

## 构建 / 检查

```sh
python source/build.py --output index.html
python tests/ux_regression.py
```

构建只依赖 Python 3。测试另需 Playwright 和 `/usr/bin/chromium`，可按本地路径修改脚本。测试浏览器因环境策略禁止 file:// 与 localhost 导航，本轮以 HTML 注入和明确的内存 Storage 适配器运行，不能据此声称已验证文件协议持久化。

源代码分层：`app.js` 提供完整数据与交互引擎；`haptic-ui.js` 保留手动控制等功能；`simple-ui.js` 决定 v0.6 的实际四页导航与日常界面；`simple.css` 对原组件做统一排版和简化。此为设计原型结构，不作为未来 Swift 工程架构。

用户尚未批准原生编码。本交付不创建 Xcode 工程，不操作 GitHub，不启动支付或云服务。

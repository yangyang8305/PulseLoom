# v0.6 UX 整合说明

## 1. 已确认的结构

主导航固定为 **首页 / 音乐 / 创作 / 我的**，不得再次删去音乐或创作入口。

首页始终表示普通震动与预设；音乐播放期间返回首页，也不会把首页变成音乐播放器。音乐的进度、文件和跟随触感属于音乐页。创作专门承载自定义，作品管理属于我的。

本版本继承原型全部 47 条路由，部分路由复用同一视图或用于模拟分支。47 条路由不等于用户需要经过 47 个页面。常用任务通过四个根页面完成，扩展工作流保持可达。

## 2. 造成旧版复杂的结构因素

1. 多次变更顶层分类，将高频音乐入口放到了“震动方式”下方。
2. 首页同时承担所有输出来源、参数控制、模式库和扩展功能导航。
3. 导入音乐还要求走来源、分析结果、继续、映射等额外步骤。
4. 参数一开始就全量暴露，默认体验需要用户先理解算法术语。
5. 选完设置仍要确认；创作中切页会打断当前操作。

以上为本项目文件与交互审阅判断，不是用户研究统计，也不能据此推导不同性别的能力差异。

## 3. 本版四页职责

| 页面 | 首屏保留 | 主操作 | 放在后面的选项 |
|---|---|---|---|
| 首页 | 普通震动标题、当前预设、6 个常用预设、强度、定时、调整触感 | 开始 / 暂停 / 停止 | 全部预设弹层；速度与质感使用文字选择，精细滑杆可展开 |
| 音乐 | 选歌按钮或当前文件、三种触感、强度、开始跟随 | 选歌 → 自动准备 → 开始 | 音乐音量、灵敏度、映射、位置、叠加、校准和区间 |
| 创作 | 敲击创作作为主要入口；绘制 / 编排 / 手势可见 | 创作 → 预览 → 保存 | 曲线数值、质感、渐入渐出、重复与时间轴细节 |
| 我的 | 作品、收藏、两个已认可主题、更多体验、记录、权益和设置 | 回到作品或换外观 | 连接、组件、隐私、购买模拟、审查工具 |

## 4. 可数的操作路径

统计从已进入 App 的首页开始，系统文件选择器中的浏览和选文件次数不计入 App 内点击。

| 任务 | App 内路径 |
|---|---|
| 开始普通震动 | 首页“开始震动”：1 次点击 |
| 换常用预设 | 点首页任一预设：1 次点击，闲置时不自动开始 |
| 选择其余预设 | 全部预设 → 点选：2 次点击，无额外确认 |
| 设置常用计时 | 定时 → 1/3/5/10 分钟：2 次点击，选择后关闭 |
| 进入音乐 | 底部“音乐”：1 次点击，无下滚要求 |
| 从示例体验跟随 | 音乐 → 先用示例试试 → 开始跟随：3 次点击 |
| 自选音乐 | 音乐 → 选择音乐 → 系统选文件 → 自动就绪 → 开始跟随；App 内 3 次点击，系统选择次数另计 |
| 切换创作/我的 | 底部各自的固定标签：1 次点击 |
| 使用已认可的皮肤 | 我的 → 柔绯/雾紫：2 次点击 |

这些是原型中的结构计数，不是完成时间测量，尚未进行最终用户可用性研究。

## 5. 默认设置与可恢复操作

- 普通震动无需选音乐或注册，直接使用原有默认预设和相对强度。
- 音乐导入后自动分析，不自动发声；点击开始才播放。
- 柔和/均衡/鲜明将多项内部参数整合为三个自然语言选择，不改变手机硬件能力。
- 定时 1/3/5/10 分钟点击即生效；自定义时长保留在展开区。
- 普通震动与音乐跟随互斥。浏览其他标签不强行丢弃当前内容；明确开始另一个输出后暂停前一个。
- 切主标签时保留编辑草稿，不要求用户每次确认“是否保留”。真正替换或删除仍需确认。
- 录完后可直接命名保存，无需被迫进入分段编辑。
- 输入时长后仅局部更新时间轴，避免失焦重绘吞掉随后的保存点击。
- 模态界面显示适当关闭入口；运行时提供停止动作。

## 6. 外观

保留用户认可的柔绯和雾紫，六套皮肤均可切换浅/深色。品牌保留衬线字，功能标题、按钮和正文改用一致的系统无衬线体系。轻柔色彩和装饰不承担主要导航含义；四个 Tab 使用明确中文标签。

日常界面减少数据面板、流程图、工程说明、重复确认和大段提示。平台能力、计费模拟和风险信息集中在恰当的说明、帮助及审查分支，底部仍明确表明震动是动画演示。

## 7. Apple 参考依据

本轮联网核查了 Apple 官方人机界面指南。以下是用于本原型的原则，四页结构本身来自用户确认，未声称是 Apple 对本产品的审定。

- **设置**：提供适用的默认值、减少设置数量，将仅影响当前任务的选项放在当前任务中。
  https://developer.apple.com/cn/design/human-interface-guidelines/settings
- **设计原则**：明确用途、建立可识别的层级、保持一致、允许恢复操作；简洁包含必要的功能，不等于删除功能。
  https://developer.apple.com/cn/design/human-interface-guidelines/design-principles
- **菜单**：新增子菜单会增加复杂度，并让其中的项目不易发现。本版不把音乐或创作放进层层子菜单。
  https://developer.apple.com/jp/design/human-interface-guidelines/menus

没有将 CSS 原型称为系统原生控件或已通过 Apple 审核。实际的 SwiftUI、系统资源与触觉行为仍需在原生阶段实现。
